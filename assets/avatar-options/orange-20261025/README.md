# Аватарки в цветах эмодзи Холодоса

Пять вариантов для выбора, созданы встроенным imagegen. Точные промпты — в `prompts.json`.
Ориентир — опубликованный набор `HolodosOrange20261025_by_holodos_recept_bot`: оранжевый, абрикосовый, сливочный, мягкие объёмные формы.

Во всех вариантах открытая дверца справа для зрителя и деревянная ложка в правой руке персонажа (слева для зрителя).
`index.html` позволяет сравнить квадратный и круглый вид; маленькие превью показывают размер 64×64.

Это варианты оформления; выбор новой аватарки не сделан.
