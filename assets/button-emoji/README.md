# Оранжевые эмодзи Холодоса

С 2026-10-27 активен новый набор [«Холодная мята»](cold-20261027/README.md).
Оранжевые файлы и опубликованные ID сохранены для истории и отката.

Созданы встроенным imagegen. `originals/` — исходные PNG с альфа-каналом;
PNG в этой папке — статические Telegram custom emoji 100×100.
Точные промпты сохранены в `prompts.json`, опубликованные ID — в `published.json`.

| Файл | Кнопки |
| --- | --- |
| dish | Подобрать блюда, выбор блюда, замена блюда |
| fridge | Из холодильника, Мои продукты |
| plan | План питания, Моё меню |
| recognize | Повторить распознавание |
| new_list | Новый список |
| shopping | Что докупить, Можно докупить 1–2 продукта |
| recipe | Открыть рецепт |
| alternatives | Выбрать другое блюдо |
| refine | Уточнить предпочтения |
| profile | Изменить профиль |
| save | Сохранить профиль |
| calendar | На день / неделю / две недели, обновить или составить меню |
| previous / next | Предыдущий / следующий день |
| back / home | Назад / Главное меню |

Иконки добавляются в `icon_custom_emoji_id`, перед текстом кнопки.
Если ID отсутствует или Telegram явно отклоняет эмодзи, обычные кнопки остаются
без значка. Только «Назад» и «Главное меню» получают Unicode ⬅️ и 🏠.
При явном отказе API иконки отключаются до перезапуска процесса.
Устаревший клиент может игнорировать иконку: Bot API не сообщает боту версию клиента.

Публикация: `scripts/publish_button_emoji.py`, владелец — `my_chat_id` из серверного config.json.
Нельзя публиковать конфиг, токен или личные данные вместе с набором.
