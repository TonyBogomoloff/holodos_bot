# Холодос · Холодная мята

19 новых минималистичных значков для кнопок. Созданы встроенным imagegen отдельно,
в одном стиле: крупный силуэт, мятная заливка, ледяные светлые детали и тёмный контур.
Палитра ориентируется на прежний холодильник: мятные детали и светлый корпус.

- `originals/` — оригиналы генерации с альфа-каналом.
- `*.png` — прозрачные Telegram custom emoji 100×100, уменьшенные FFmpeg/Lanczos.
- `generation.json` — все точные промпты, палитра и происхождение файлов.
- `pack.json` — название набора и порядок значков.
- `published.json` — проверенные Telegram ID и SHA-256 каждого опубликованного PNG.
- `index.html` — тёмное превью, включая реальные размеры 20 и 24 px.

Набор: https://t.me/addemoji/HolodosMint20261027_by_holodos_recept_bot

Прежняя аватарка восстановлена из
`assets/avatar-options/orange-20261025/references/current-avatar.png`.
Это исходник холодного варианта `08-realistic-right-hand.png`, сохранённый до
перехода на оранжевое оформление. SHA-256:
`0fbe95e5e66870bdd92614a4b708fa4c44e08bc6daa73fb6e4bd208124516fc0`.

К 16 основным значкам добавлены `help`, `privacy`, `delete`.
`previous`/`next` работают и для дней меню, и для длинных экранов рецепта/списка.
Оранжевый набор сохранён: прежние ID и уже отправленные сообщения не изменяются.
Новые и обновляемые кнопки получают новый набор. При отказе Telegram сохраняется
прежнее поведение: без эмодзи, кроме обычных ⬅️/🏠 для навигации.

Повторная проверка публикации на сервере:

```sh
python scripts/publish_button_emoji.py \
  --assets assets/button-emoji/cold-20261027 \
  --pack assets/button-emoji/cold-20261027/pack.json \
  --receipt assets/button-emoji/cold-20261027/published.json
```

Секреты и владелец читаются только на сервере; в набор и репозиторий не попадают.
